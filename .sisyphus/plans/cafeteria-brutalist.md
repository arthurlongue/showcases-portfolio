## Context

### Original Request
The user provided a single-file React component (with embedded raw CSS) generated by Google AI Studio. It represents a brutalist coffee shop design featuring Framer Motion v12 (`motion/react`) animations, Marquee text, and custom CSS variables (`--color-brutal-bg`, etc.).

### Interview Summary
**Key Discussions**:
- **Route Handling**: The existing `/premium/cafeteria` (Aura Roasters) will be moved to `/premium/assinatura-cafe`.
- **New Showcase**: The AI-generated brutalist code will take over the `/premium/cafeteria` route.
- **CSS Strategy**: Keep custom CSS organized and manageable without leaking into other pages.
- **Testing**: No TDD or automated unit tests. Use Agent-Executed QA scenarios via Playwright.

### Metis Review
**Identified Gaps** (addressed):
- **CSS Scoping Risk**: Raw `@theme` in a local CSS file leaks globally in Tailwind v4. Resolved by defining variables inside a scoped `.cafeteria-theme` class and applying it to the new `layout.tsx` wrapper.
- **Motion Import**: Verified that `motion/react` is correct for Motion v12.
- **Font Loading**: Needs proper configuration of `Anton`, `Inter`, and `JetBrains Mono` via `next/font/google`.
